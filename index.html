Section 0

Hardware: a new device on a different bus

The LSM303DLHC (U5) is two I²C devices in one package. It sits on bus 1, not the bus 0 your Lab 5 temperature sensor used. Remap SCL/SDA to I2C_SCL_1 / I2C_SDA_1 in xem7310_v1_fixed.xdc.

An I²C address byte is the 7-bit address shifted left by one, with the R/W bit in bit 0. So 0x19 becomes 0x32 to write and 0x33 to read.
Section 1

What to change in your I²C master

  1. Device address becomes a parameter or input: 0x19 (accel) or 0x1E (mag).
  2. Support the three transactions below.
  3. Make the auto-increment bit (top bit of the register address) a switch Python controls.
  4. Return all 6 bytes to the host through FrontPanel wires or a pipe.
START / Sr / STOP byte the FPGA sends byte the sensor sends ACK from sensor ACK/NACK from FPGA

Sr = repeated START: switch from writing the register address to reading, without releasing the bus. The last byte read gets a NACK, which tells the sensor to stop sending.

The register-address byte (0xA8)

One byte, two jobs. Bit 7 is a flag, not part of the address. Bits 6–0 are the first register of the burst. You send it once; the sensor moves its own pointer.

Why it reads nothing at power-up: CTRL_REG1_A powers on as 0x07. The axes are enabled, but the data rate field is 0000, which means power-down. You must write it before any data appears.

Task 1c

The gravity check

Rest the board six ways so gravity lines up with each axis in each direction. In each, average a few hundred samples. The axis pointing up reads about +1 g; the other two read about 0.

Task 1d

Sustain 100 samples per second

Hold ≥ 100 three-axis samples/s for ≥ 30 s, timed in Python. 100/s means each sample has a 10 ms budget. Drag the sliders to see where the time goes.

Clock count: each byte is 8 bits + 1 ACK = 9 clocks; START, Sr and STOP add about one each. Burst: 0x32, 0xA8, 0x33, D0–D5 = 9 bytes. Single read: 0x32, SUB, 0x33, D = 4 bytes, done 6 times. The bus time is small; the per-transaction host overhead is what kills six singles.
